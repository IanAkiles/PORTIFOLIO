# Portfólio de Ian Akiles

Site estático com projetos, contato e experiências interativas. A página usa módulos JavaScript, então rode a prévia por HTTP.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Execute o comando na raiz da cópia local e abra `http://127.0.0.1:8000/`.

- [`index.html`](index.html) é a página principal.
- [`js/data.js`](js/data.js) reúne o conteúdo dos projetos.
- [`media/SOURCES.md`](media/SOURCES.md) registra a origem das mídias.
